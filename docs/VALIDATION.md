# حالة التحقق

المشروع في جذر CRM بعد استبدال شجرة ERP. يوجد APK بوضع Release موقّع، لكن هذا لا يعني اكتمال التحقق الوظيفي أو أمان التدقيق الحي.

## ما نجح

- نجح `flutter analyze` من جذر المستودع باستخدام Flutter 3.50.0: `No issues found`.
- نجح `flutter build apk --release` باستخدام JDK 21 الكامل. لم تُعطّل فحوص Lint؛ محاولة JDK 17 السابقة تعطلت داخل Lint بخطأ `java.util.List.removeLast()`.
- APK: `build/app/outputs/flutter-apk/app-release.apk`؛ الحجم نحو 54.3 MB. تحقق من SHA-256 الحالي قبل أي توزيع.
- أكد `aapt` الحزمة `cloud.lork.audit.standalone` وversionName `1.0.0` وversionCode `1`.
- تحقق `apksigner` من توقيع v2 وشهادة Release ذات SHA-1 `B1:12:AB:9A:C6:2B:E1:57:DA:D6:3D:ED:8C:1E:49:B0:CB:CE:46:3B`.
- أُنشئ عميل Android OAuth منفصل لـRelease، وتحققت حقول الحزمة والبصمة المحفوظة؛ لم يُعدّل عميل Debug.
- مرجع إعداد الإصدار والتحذير الأمني في [RELEASE_SIGNING.md](RELEASE_SIGNING.md).

## انكشاف بيانات التوقيع

بموافقة صريحة من المالك، ستُدرج ملفات `android/app/lork-audit-release.jks` و`android/key.properties` (وتتضمن كلمة مرور المخزن وكلمة مرور المفتاح) في المستودع العام. تعامل مع المفتاح والبيانات باعتبارها مكشوفة/مخترقة؛ ستبقى في تاريخ Git والنسخ المستنسخة حتى لو حُذفت في commit لاحق. راجع تحذير التسرب واستراتيجية التعامل معه في [مرجع الإصدار](RELEASE_SIGNING.md).

## قيود Google والاختبارات

OAuth ما زال **External / Testing**، وحساب `loorksy@gmail.com` ضمن مستخدمي الاختبار. النشر العام غير مكتمل؛ زر Publish app معطّل حتى استكمال Branding. إنشاء عميل OAuth لا يثبت تسجيل الدخول داخل التطبيق أو الوصول إلى الملفات.

لم يُشغّل `flutter test` أو أي اختبار Google أو Android، ولم يُثبّت أو يُشغّل APK على جهاز أو محاكي، وفق تعليمات المستخدم. اختبارات Unit وWidget وSQLite والتكامل الاصطناعي موجودة لكنها غير منفذة.

لم تُقرأ أو تُكتب أوراق Google حقيقية. ما تزال `AuditSyncEngine._writesEnabled()` تعيد `false`: لا إنشاء أوراق ولا نسخ صفوف ولا تلوين ولا تحديث حالة. حفظ الخطة وإعادة التحقق لا يثبتان مزامنة خارجية.

قفل SQLite وسجل الأحداث موجودان، لكن التعافي بعد قتل العملية أو مع WorkManager غير مثبت. القفل لا يحل تحرير Google المتزامن بعد آخر قراءة ولا يوفر معاملة ذرية عبر ملفات Google. لا تفتح بوابة الكتابة قبل اختبارات منفصلة للتكرار والمهلات والنتيجة غير المؤكدة والتعديلات الخارجية ونقل الصفوف والحماية والصلاحيات ومراجعة الآثار.

بقي تحذير مستقبلي حول استخدام إضافتي `file_picker` و`workmanager_android` لـKotlin Gradle Plugin؛ البناء الحالي نجح، لكن يلزم مراجعة التوافق مستقبلًا.
